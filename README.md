# 找回网

静态网页 ARG。主站是 00 年代失物门户，Danny 的个人站是带游客区和员工镜像的旧网页。HTML、CSS、JavaScript 分别位于 `html/`、`css/`、`js/`，精确图文线索位于 `assets/`。双击根目录 `index.html` 可打开；完整跨页存档建议通过同一 HTTP 源访问。

在线地址：https://znso4pagame.github.io/arg-laf/

## 本次结构

主站有 12 条普通登记，支持名称、同义词、编号、地点、描述和关联词搜索。钱包不再是唯一开头；相机套、证件套和票根保留同源的旧网页存档。入口在登记详情的“登记来源与转录说明”中，不再为每个搜索词插入求救卡。普通登记也可主动保存至“我的”。相关查询来自当前结果的公开标签。

Danny 相关调查全部发生在 `html/danny.html`。随记、相册、留言簿、账户、工作匣和旧柜是同站栏目，切换栏目不离开个人站。旧的修订页、登录页、工作台和归档室地址只作兼容跳转。

- 游客：阅读公开随记、相册和留言，可以站内搜索、翻照片背面并保存材料。
- 员工：拼出凭证后在原站升级权限，新增工作匣与私有搜索。无需按规定顺序收集或达到虚假的线索数量。
- 旧柜：根据工作材料定位后，仍在站内阅读旧档、选择比较材料、标记差异、填写证据关系。混有不同年代与用途的文件，只有同一事件的原件和副本可以通过核对。

干扰信息包括生活随记、个人昵称、旧班次、试值勤日期、上传日期、维修单号、耗材柜号与后期改造工程号。每项都有出处和可排除的依据，未引入场外编码表或随机答案。界面不显示解谜清单或完成百分比。

“我的”保留实际取得的材料，支持分类、重点、备注、个人笔记与两份材料并排对照。线索辅助默认关闭，按需开启后仅校对公开物品和已收集材料，不揭示员工口令。终局签署或放弃仍需确认，普通关闭和换页不算终局。

参考用户提供的[谜页集](https://miyeji.cn/)及其[《消失的23班》作品介绍](https://miyeji.cn/games/xiao-shi-de-23-ban)：从日常需求进入普通网页，再从旧内容追查。只借鉴叙事入口和信息组织方式，本站文本、谜底与图像独立编写。未对参考作品作完整游玩或视觉复刻。

## 存档和验证

继续使用 `localStorage` 的 `zhaohui-journey-v2` 保存线索、笔记和终局，保留已有玩家的材料。员工会话仅放 `sessionStorage`，新版会话与旧版隔离；上版会话不会直接开放新版个人站。关闭标签页或退出后可重新登录恢复，口令不落盘。清除新版记录不改旧版 `zhaohui-story-v1`。

这是公开源码中的虚构账号谜题，不是真实身份认证；源码可读到全部谜底，请勿用于现实个人资料。存储受限时主站使用内存；员工会话建立失败会明确反馈。

```sh
npm ci
npm test
npm run build
```

DOM 测试覆盖多入口搜索、来源折叠、游客与员工范围、旧会话、错误干扰答案、同站完整调查、照片翻面、原件选择、终局、笔记和构建依赖；另测纯匹配算法与存储降级。DOM 检查不代替真实浏览器的视觉与兼容性验证。

推送 main 后 GitHub Actions 自动测试、构建和发布 Pages，输出为 `_site/`，JS/CSS 使用内容指纹。
