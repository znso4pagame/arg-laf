# 找回网

静态网页 ARG，2000 年代的失物门户与老式馆务员工站。HTML、CSS、JavaScript 分别位于 `html/`、`css/`、`js/`，精确图文线索位于 `assets/`。双击根目录 `index.html` 即可打开；完整跨页存档建议通过同一 HTTP 源访问。

在线地址：https://znso4pagame.github.io/arg-laf/

## 新版玩法

从丢失的物品进入，打开异常登记，追查原始附件。线索不再组成一串必须精确输入的搜索指令，而是跨页面的图文调查：找回网 → 修订页 → Danny 的馆务员工站 → 档案柜 → 两版市政档案 → 证据关联 → 人员认领选择。

“我的”只保存实际取得的材料，可以分类、标记重点、为每份材料写备注，也可以写独立笔记、选择两份材料并排对照。个人推测不会自动成为已验证事实。线索辅助默认关闭，手动开启后按 50% / 70% / 完整匹配提供 A / AB / ABC 片段，仅比较公开物品与已收集材料，不预告隐藏剧情。

登录、柜号、档案差异和证据关联各自有明确的失败反馈。归档室使用一次短暂的静态遮屏制造反差，不播放声音、不闪烁；可在登录页减少突变效果，也遵循系统减少动态效果偏好。签署和放弃均需二次确认；关闭页面、刷新和换页均不算终局。

## 剧情改编说明（剧透）

原始 `ARG storyline.docx` 保留不动。新版保留小鹿受困、Harrow House、Elias Rook 被归为物品，以及认领导致岗位继受的核心反转。为消除原稿中 Danny 同时作为馆务员工、客服 0002 与历史签收人的混用，新版将 Danny 的馆务账号与工牌独立；0002、0003 作为历史凭据流水号，Q-17 作为那次签收人的代号。新流程不要求顺次搜索原稿关键词。

## 存档与运行

新版使用 `localStorage` 的 `zhaohui-journey-v2`，与旧版存档隔离；清除新版不会改旧记录。员工会话仅保存于 `sessionStorage`，关闭会话后重新登录即可恢复调查；不保存口令。存储被拒时主站改用内存，员工登录会明确提示无法建立会话。

这是公开源码中的虚构账号谜题，不提供真实身份认证，不能用于保存现实个人资料。静态页面中的全部谜底都可通过阅读源码得知。

## 开发与发布

```sh
npm ci
npm test
npm run build
```

`npm test` 通过 jsdom 执行真实页面的 DOM 事件，覆盖完整新流程、错误答案、跨页存档、直接访问、输入法、材料笔记和终局确认，另验证纯匹配算法、存储降级和构建产物。它不代替真实浏览器的视觉和兼容性验证。

构建输出 `_site/`，JS/CSS 使用内容指纹；原 HTML 仍可直接读取。推送 `main` 后 GitHub Actions 自动测试、构建并发布 Pages。
