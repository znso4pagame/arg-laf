# 找回网

静态网页 ARG。主站是 00 年代失物门户，Danny 的个人站是带游客区和员工镜像的旧网页。HTML、CSS、JavaScript 分别位于 `html/`、`css/`、`js/`，精确图文线索位于 `assets/`。双击根目录 `index.html` 可打开；完整跨页存档建议通过同一 HTTP 源访问。

在线地址：https://znso4pagame.github.io/arg-laf/

## 本次结构

主站有 16 条普通登记，支持名称、同义词、编号、地点、描述和关联词搜索。钱包不再是唯一开头；相机套、证件套、票根、保温杯与纸本登记保留同源的旧网页存档。入口在登记详情的“登记来源与转录说明”中，不再为每个搜索词插入求救卡。普通登记也可主动保存至“我的”。相关查询来自当前结果的公开标签。

Danny 相关调查全部发生在 `html/danny.html`。随记、相册、留言簿、账户、工作匣和旧柜是同站栏目，切换栏目不离开个人站。旧的修订页、登录页、工作台和归档室地址只作兼容跳转。

- 游客：阅读公开随记、相册和留言，可以站内搜索、翻照片背面并保存材料。
- 员工：拼出凭证后在原站升级权限，新增工作匣与私有搜索。无需按规定顺序收集或达到虚假的线索数量。
- 旧柜：根据工作材料定位后，仍在站内阅读旧档、选择比较材料、标记差异、填写证据关系。混有不同年代与用途的文件，只有同一事件的原件和副本可以通过核对。

干扰信息包括生活随记、个人昵称、旧班次、试值勤日期、上传日期、维修单号、耗材柜号与后期改造工程号。每项都有出处和可排除的依据，未引入场外编码表或随机答案。界面不显示解谜清单或完成百分比。

“我的”保留实际取得的材料，支持分类、重点、备注、个人笔记与两份材料并排对照。线索辅助默认关闭，按需开启后仅校对公开物品和已收集材料，不揭示员工口令。终局签署或放弃仍需确认，普通关闭和换页不算终局。

## 动效打磨

动效由 `js/motion.js` 与 `css/motion.css` 单独维护：主站列表短错峰淡入，栏目切换与材料展开使用轻微位移，照片翻面仅转动扫描区域，时间排序按元素前后位置平滑移动，错误与成功各有短促反馈。对照只更新换过的一侧，保留另一张纸的阅读位置。终局移交的装饰进度缩短，不延迟内容或操作。

扫描附件支持 100%–300% 缩放，短过渡尽量保持当前阅读中心；扫描区获得焦点后可按 `+` / `-` 缩放、`0` 恢复适合大小，也可使用“适合”按钮。收起照片背面后回到正面目录；收藏筛选、重点标记和搜索重绘保留操作焦点。关闭材料或弹窗立即取消对应动画。

所有逻辑在动效启动前完成，不用动画结束回调解锁资料。连续操作、替换 DOM 和离开页面会取消旧动画；无动画 API 时直接显示内容。主站页脚的“减少动态效果”和 Danny 账户页选项共用设置，系统减少动态偏好优先，切换后立即取消正在运行的动画。普通跨窗口笔记更新不会重播列表入场。

动效回归使用 DOM 与动画 API 模拟，验证取消、完成、降级、偏好切换和状态立即生效；这不等同于真实浏览器的帧率或视觉观感验证。

## 重玩与终局复查

另一个窗口已经保存结局时，迟到的旧确认按当前实际记录显示，不再显示另一种结局或错误的签署姓名；来自旧轮次的确认不能结束新一轮。存储事件和页面缓存恢复都会刷新终局、目标及辅助开关。注销后在主站完成开场，停在重开提示的 Danny 窗口会恢复游客查阅。

拾物登记会拒绝只含空格的名称、地点或描述，保留填写内容并标出待修正字段。DOM 回归覆盖注销后完整重玩、两条调查线、证据核验及第二种终局。

## 注销与返回流程

主站导航和 Danny 页顶均提供“注销”。确认后清除本轮进度、线索、笔记、查询与登记、结局和员工会话，回到开场；取消不会清档。“退出员工模式”仍只退出当前员工登录。重开会生成新的轮次标识，旧历史记录、旧材料深链接与页面缓存不会自动恢复上一轮调查或登录。仅清理本游戏使用的存档和会话键，不清空整站浏览器存储。

主站菜单、查询、“我的”与申请页同步地址和 History API 状态，前进后退与刷新恢复对应内容；各标签页的查询快照独立。未提交的搜索不会因其他窗口更新而被自动执行。Danny 同栏目返回复用现有工具，跨栏目工具草稿仅留在当前页面内存，退出和注销时清理。

## 游玩衔接复查

- 两条员工调查线各有独立入口，点击后直接定位到排序、柜号、档案对照或关系核验工具；同栏目定位保留当前输入。会话已恢复但未阅读时直接打开正文。
- 游客读齐身份与个人备忘涉及的材料后，当前目标转向账户入口。无关地点的普通登记不会被算作旧馆来源进度。完整核验后可直接回主站决定，无须恢复员工会话。
- 从已收集材料返回私有原文时，登录会保留请求的位置；旧柜仍遵守实际调取权限。
- 阅读中目标说明自动收紧，保留标题和主入口，手动展开及查阅脉络的展开状态可跨材料保留。
- 其他窗口保存普通笔记不再重建正在填写的登录表单；主站未提交姓名在进度刷新时保留，清空输入与重新开始会清除草稿。口令仍不落盘，跨窗口重置会立即撤回私有阅读权限。

## 排版与主线引导修订

开场新增“旧登记通知”的具体来由，明确先从物品和通知地点核对来源。主站与 Danny 站均提供随已取得材料更新的当前目标和继续查阅入口；员工阶段明确会话恢复、旧案查证两条并行线，未调取旧柜时不会把继续按钮送往锁定页面。查阅脉络可折叠，不列账号、口令或柜号答案，也不通过看提示解锁进度。既有存档直接接续；查阅顺序不同也可走到最终选择，站内“我的”和申请链接会立即切换到对应内容。

排版修复包括：手机搜索框的零宽度问题、Danny 站 651–680px 的断点冲突、浅色弹窗标题看不清、长标题与字段撑开、窄屏扫描工具栏和排序按钮挤压。统一紧凑布局为 760px，宽屏阅读分栏从 1120px 开始；中间宽度先显示原文再接目录，手机集中阅读。档案对照使用专门宽弹窗和局部横向表格滚动区，正文按页面自然滚动。

已做 320、375、650、660、680、760、761、900、1024、1440px 下两种页面的 CSS 解析与生效断点声明检查。这只验证样式规则，未测量浏览器几何，也未完成真实浏览器视觉或实机验证。

## 随身拾获物支线

开场交代玩家在旧馆站拾到三样尚未上交的物品：“我的”里可检查黄铜小钥匙、折起的旧纸包和褪色蓝卡套。主站查询“你丢了什么”，或沿小鹿的接待回应继续追问，可逐句取得她的失物特征。检查物品并听完三句描述后才能交还；错误物品留在袋中，小鹿的核对回应只在搜索建议出现，同一种错误不重复说话。

正确交还后，旧纸包与蓝玻璃珠离开随身袋，小鹿在查询建议中提供旧页面地址，交还回执保留这条索引，开放 Danny 个人站的来访便笺。这是一条可选调查入口，不自动授予员工身份，也不代替人员认领。奖励便笺同样受查阅权限控制，不能靠搜索或直接地址提前取得。物品检查、交还和回执跨刷新保存，跨窗口同步；注销重置，旧轮次或终局后的交还不会改变进度。存档线索容量扩展为 200 条，以容纳新增对话、物品回执和玩家自己的登记。
