# 找回网

一个使用纯 HTML、CSS、JavaScript 制作的失物招领 ARG。表面为蓝白色的旧式公益信息门户；玩家从寻找失物开始，逐步核对异常登记、历史签收凭据与客服对话。所有人物、网站与档案均为虚构。

在线地址：[找回网](https://znso4pagame.github.io/arg-laf/)。

## 直接打开

用浏览器打开根目录 `index.html` 即可。本地运行不需要安装依赖或构建。也可以运行 `python3 -m http.server 8080`，访问 `http://localhost:8080`。

`html/guide.html` 是独立的“入站小记与使用说明”，没有脚本，也不依赖弹窗。首页的说明入口使用真实链接。已有进度不会被开场打断。

## 交互与剧情规则

- 首次进入可填写失物名称或略过引子；已读引子和旧版进度不会被自动重置。页面保留最初的寻找目标。
- 异常卡片先打开原始备注，玩家主动询问后才开始交流。寒暄与任意句子不生成异常登记。
- 小鹿只在搜索建议中回应。普通文字用于阅读，带箭头的问题和索引用于继续查询；不再把所有台词都伪装成按钮。手动检索一句台词不会被隐藏别名改成另一个问题。自然表达仅匹配同义意图，如“我的钱包呢”“我该怎么帮你”。看到认领表后，可直接询问“我认领你之后会怎样”，不用猜中“岗位职责”四个字。
- 开放条件来自实际显示出来的编号、关联入口和索引，而不只记录“提交过哪个词”。未显示的地点回复不算发现该地点；主动请求第三层提示可以获得明确索引。招聘、签收链和 Danny 记录可按需要追查，不是领取申请的必经口令。
- 每次回应按语境分别记录实际已显示的句子。输入新内容、中途换页或刷新不会把未读完的建议永久吞掉；“继续查看”只补完未显示的部分。已完整显示的同一语境不重新发言。检索帮助分三级，按需展开。
- 0002 与 0003 是历史登记流水号：Q-17 是旧凭据的签收人，随后又出现在物品名称栏。这构成疑点，不在此处直接解释岗位替换。
- Danny 是独立协查访客 D-2019，不是历史流水号 0002 的签收人。他的认领申请未签署、未提交，不能同时视为完成了岗位移交。其馆内失踪记录另行保留。
- 第一次接触后就可以追问自己的失物或询问如何帮忙。工牌尚未确认时返回查询委托；确认工牌后再追问，会出现待核验的人工补录。可以先看申请，也可以先核对旧档案。审核页只展示凭据缺失与申请对象；对方的承诺仍是建议中的发言，新证据出现后会露出不同的说法。
- 最终签署先显示对象、姓名、理由的核对窗口，最后确认才生效；放弃也需要单独确认。取消任一窗口都会返回原草稿。普通关闭、刷新、前进后退和查阅说明只暂停，不猜测玩家是否决定放弃。这是对原稿关闭即结局规则的明确化调整。
- 最终沉默后不再添加新台词，但未显示完的最后几句仍可续读。已经开放的档案和最终选项可继续使用。签署防重复，姓名始终按文本显示。
- 查询有前后翻阅记录，最多保留 24 个查询视图。刷新、返回说明页和浏览器缓存恢复会还原当前记录、已显示的建议与草稿，不重新推进剧情或发言。
- 多标签页以记录版本号保护进度；旧页面离开或迟到的保存不能覆盖另一页面较新的结局或重置。
- 普通拾物登记、申请与回执仅保存到本机，不发送到服务器。清除本机记录会清除全部本机数据并重新展示开场。

原稿对 Danny 与 0002 身份、拒签与认领完成存在不同说法。当前实现以“历史签收链”和“Danny 的未签申请”为两份独立证据统一因果；原始 DOCX 保留不改。

## 开发与发布

仅测试、打包需要 Node.js 24 或更高版本：

```sh
npm ci
npm test
npm run build
```

测试在离线 DOM 与虚拟时钟中验证证据门槛、逐条回复、错误台词映射、普通和特殊表单、旧存档迁移、刷新及说明页返回、结局、输入法与发布包完整性。它们不替代真实浏览器的点击、排版验收。

Pages 工作流每次推送 `main` 后运行测试，再将 `_site/` 发布上线。打包为 JS/CSS 生成内容指纹，并给页面入口附加版本；旧静态资源地址保留兼容。原始文档、开发依赖与测试不进入部署包。

每完成一批可用改动，检查通过后提交并推送到 [GitHub 仓库](https://github.com/znso4pagame/arg-laf)。

## 维护者验证路线（含剧透）

这是一条可选的完整调查路径，不是通关口令表。每个索引须从实际显示的记录、建议或主动提示中发现。玩家不必先读完历史支线才有资格追问自己的东西。

```text
钱包 → 打开异常登记详情 → 询问“你是谁”
→ 小鹿（可选身份查询）→ 你在哪 → B3 → 入职记录
→ 0002 → 0003 → 上一个 → 他问了什么 → 他走了
→ 我的东西 → 审核 → 认领表 → 免责条款 → 岗位职责
```

“骗我”是查到 0003 后可选的质问，不再强制。“为什么 → 招聘广告 → 合同 → B3”是另一条地点发现路径；“别的办法 → 改分类 → Elias Rook → Harrow House”提供背景。最终可以签署或放弃，清除本机记录后可重新体验。

更短的主动寻找路径：`钱包 → 你是谁 → 我的东西 → 你在哪 → B3 → 再问我的东西 → 审核 → 认领表`。此时仍可从申请中的档案入口回头调查 0002、0003 或提出质疑。新证据会改变后续同词回应。
