# 找回网

根据《ARG storyline.docx》制作的静态 ARG 网页。表面是失物招领平台，玩家通过搜索建议、异常登记和历史档案逐渐接近 B3 层的真相。所有人物、平台与档案均为虚构。

## 本地打开

直接用浏览器打开根目录 `index.html` 或 `html/index.html`。运行网站不需要安装任何依赖，也不需要构建。

如需 HTTP 预览，在项目目录运行：

```sh
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。本地文件与不同 HTTP 地址使用各自的浏览器存储；请使用固定的打开方式继续游戏。

## 文件结构

```text
index.html                  根入口，跳转到 html/index.html
html/
  index.html                页面结构
css/
  style.css                 基础布局和响应式样式
  interaction.css           动效、交互反馈和减少动态效果适配
js/
  data.js                   失物数据、关键词、线索和别名
  app.js                    搜索、表单、进度、持久化和结局
  tests/
    interaction.test.cjs    离线 DOM 交互回归测试
ARG storyline.docx          原始故事设定
```

## 已实现的交互

- 搜索提供加载反馈。连续查询、修改输入或返回首页会取消过时请求，旧结果和旧建议不会覆盖新操作。
- 线索建议在结果返回后逐条浮现，和普通建议使用相同样式。点击即可继续搜索；同一词条不重复回复。
- 支持中文输入法组合输入、全角字符和英文大小写匹配。建议可用上下方向键选择，Enter 提交，Escape 收起。点击搜索框可重新展开建议。
- 最近查询保留 12 条，可以重新查阅已打开的档案。提前输入深层关键词会得到当前阶段可继续查找的词条。
- 寒暄、天气、系统、工资和“救我”等词不触发小鹿，且不会被记成最初丢失的物品。
- 失物卡片支持详情、普通认领申请与回执；拾物登记保存在本机，刷新后仍可查看。没有服务器，不会真的联系失主或提交认领。
- 剧情认领表在站内跳转时保留姓名与理由草稿，并提供返回未完成表格的入口。空白姓名不能提交。
- 填写剧情认领表后经过审核、岗位移交、黑屏揭示三个阶段进入身份转移结局；重复提交不重复触发。
- 在认领阶段选择放弃，或关闭/刷新页面再打开，进入离开结局。点击站内首页或品牌标志不会意外触发离开。浏览器前进/后退缓存恢复也会处理结局。
- 另一标签页更新进度时，同源页面会同步状态；页脚可清除全部本机游戏记录、登记和申请。
- 凭证轻浮、卡片悬浮、档案扫描、记录淡入和弹窗反馈配合剧情节奏；尊重系统“减少动态效果”设置，无音频、无强烈闪烁。

搜索“钱包”，点击异常登记即可开始。注意搜索框下方本来不该说话的地方。

## 开发与测试

仅开发测试需要 Node.js 24 或更高版本：

```sh
npm ci
npm test
```

测试在本地 DOM 和虚拟时钟中运行，不启动浏览器、不访问网络，覆盖请求取消、输入法、剧情门槛、主线和支线、草稿、普通认领、两种结局、跨页恢复、跨标签同步、存储异常及减少动态效果。测试不等同于浏览器中的视觉检查。

每完成一批可用修改，检查通过后提交并推送到 [GitHub 仓库](https://github.com/znso4pagame/arg-laf)。

## GitHub Pages

`.github/workflows/pages.yml` 在推送到 `main` 后运行交互测试，通过后部署静态网站。需要先在仓库设置中启用 GitHub Pages，构建来源选择 GitHub Actions，并确保账户套餐支持此仓库的 Pages 服务。

部署内容仅包括页面、样式和运行脚本，不包含原始剧情文档、测试文件或开发依赖。使用 GitHub Pages 的项目子路径时，根入口和所有资源均通过相对路径访问。

## 开发者路线（含剧透）

主线：

```text
钱包 → 点击异常登记 → 我是小鹿 → 你在哪 → B3 → 入职记录
→ 0002 → 0003 → 骗我 → 上一个 → 他问了什么 → 他走了
→ 我的东西 → 审核 → 认领表 → 免责条款 → 岗位职责
```

资料支线：`为什么 → 招聘广告 → 合同`、`别的办法 → 改分类 → Elias Rook → Harrow House`。

搜索“岗位职责”后，小鹿沉默。已开放的档案和“返回未完成的认领表”仍可使用。提交姓名与认领理由进入身份转移结局；不填并离开进入放弃结局。两种结局均可通过页脚清除本机记录后重新体验。

原稿中关于时间、Danny 身份和链条存在不同版本；页面将时间错位保留为档案异常，并分别呈现链条记录与对话缓存。
